# Умра с Ильфатом — локальный черновик

Открыть `dist/index.html` напрямую или запустить `python preview.py`, затем перейти на http://127.0.0.1:4173.

Сайт статический, без сборки и внешних зависимостей. Телефон открывает звонок, меню работает на мобильном, фотографии открываются крупно, вопросы раскрываются. Прототип исключён из индексации тегом robots noindex.

Публичный адрес черновика: https://a6340374-stack.github.io/umra-ilfat/. Публикация папки `dist` выполняется GitHub Actions после обновления ветки `main`.

До окончательного запуска подтвердить программу и длительность, состав пакета, доплаты и форматы индивидуальных поездок. Пользователь явно разрешил публичную публикацию черновика с телефоном и предоставленными фотографиями. Отзывы и неподтверждённый опыт не добавлялись.
