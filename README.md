# Умра с Ильфатом — локальный черновик

Открыть `dist/index.html` напрямую или запустить `python preview.py`, затем перейти на http://127.0.0.1:4173.

Сайт статический, без сборки и внешних зависимостей. Телефон открывает звонок, меню работает на мобильном, фотографии открываются крупно, вопросы раскрываются. Прототип исключён из индексации тегом robots noindex.

До публикации подтвердить программу и длительность, состав пакета, доплаты, форматы индивидуальных поездок и возможность публикации фотографий. Отзывы и неподтверждённый опыт не добавлялись. Сайт ещё не опубликован.
