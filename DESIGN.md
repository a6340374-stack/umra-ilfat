# Дизайн прототипа

Графитовый и тёплый золотой взяты из согласованного референса. Реальные фотографии — основное доказательство поездок. Светлые разделы делают условия читаемыми.

Токены: фон #202622, текст #262d27, золото #d6bc80, светлый фон #f7f5ee, вторичный текст #62695f. Шрифты Georgia для заголовков, Segoe UI для текста. Контент максимум 1240px. Кнопки от 48px высотой. Скругления сдержанные: 4px, изображения 8px.

Главная задача: увидеть дату и цену, понять личное сопровождение, позвонить. На мобильном — закреплённая кнопка звонка, меню раскрывается кнопкой. Галерея открывает полноразмерные фото; Escape закрывает просмотр.

Афиша поездки: самостоятельный раздел #poster на светлом фоне. Изображение целиком без обрезки, максимум 440px, справа заголовок, даты, звонок и скачивание; на мобильном — одна колонка. Открывается существующим просмотрщиком фото.
