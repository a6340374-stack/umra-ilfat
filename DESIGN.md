# Дизайн прототипа

Графитовый и тёплый золотой взяты из согласованного референса. Реальные фотографии — основное доказательство поездок. Светлые разделы делают условия читаемыми.

Токены: фон #202622, текст #262d27, золото #d6bc80, светлый фон #f7f5ee, вторичный текст #62695f. Шрифты Georgia для заголовков, Segoe UI для текста. Контент максимум 1240px. Кнопки от 48px высотой. Скругления сдержанные: 4px, изображения 8px.

Главная задача: увидеть дату и цену, понять личное сопровождение, позвонить. На мобильном — закреплённая кнопка звонка, меню раскрывается кнопкой. Галерея открывает полноразмерные фото; Escape закрывает просмотр.

Афиша поездки: самостоятельный раздел #poster на светлом фоне. Изображение целиком без обрезки, максимум 440px, справа заголовок, даты, звонок и скачивание; на мобильном — одна колонка. Открывается существующим просмотрщиком фото.

Мобильная афиша компактная: ширина min(100%, 280px, 32svh), центрирована, исходные пропорции сохранены. Отступы раздела 32px, заголовок 29px. CSS подключается с версией в URL для обновления ранее закэшированных стилей.

Кнопка «Поделиться афишей» отправляет ссылку на сайт через системное меню с датами, ценой и телефоном. Для предпросмотра ссылок Open Graph и Twitter используют исходное фото Ильфата (ilfat-link-preview.png, 458×826). Отдельные кнопки Telegram/WhatsApp удалены по просьбе пользователя, осталось прямое копирование ссылки с ручным запасным полем. Для обновления кэша превью передаётся URL ?v=ilfat-photo#poster. Старые отправленные карточки не меняются автоматически. Фавикон: квадратный SVG с встроенным исходным фото и кадрированием средствами viewBox, PNG-портрет для запасного значка и Apple touch icon.

Рядом с кнопкой общий счётчик CountAPI (countapi.mileshilliard.com): ключ umra-ilfat-poster-2026-11-28-a6340374. Учитывает завершение native share или копирование ссылки, максимум один раз на браузер с localStorage. Это приближённый счётчик действий, не подтверждённых отправок или уникальных людей; пояснение видно рядом. Нет имён или идентификаторов в запросах, referrer не передаётся. Публичный сторонний счётчик без гарантии доступности и защиты от накрутки; недоступность показывается тире, не вымышленным числом. Очистка localStorage и другие устройства могут приводить к повторам.
